# FlowFans

A mainstream-ready platform where fans support creators through micro-tipping, subscriptions, and exclusive content access - leveraging Flow's ultra-low gas fees to make $0.50 tips economically viable

Package manager: npm.

## Commands

- dev: `npm run dev`
- build: `npm run build`
- lint: `npm run lint`

## Layout

- `app/`
- `lib/`
- `public/`

## Rules

- Never commit secrets or `.env` files.
